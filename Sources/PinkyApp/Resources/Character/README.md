# Character Sprite Frames

This directory is the runtime source for mascot animation frames.

## Required structure

Each state folder should contain PNG frames named with a numeric suffix:

- `Idle/idle_01.png`, `idle_02.png`, ...
- `Walk/walk_01.png`, `walk_02.png`, ...
- `Blink/blink_01.png`, ...
- `Drink/drink_01.png`, ...
- `Wave/wave_01.png`, ...
- `Happy/happy_01.png`, ...
- `Sad/sad_01.png`, ...
- `Sleep/sleep_01.png`, ...
- `Peek/peek_01.png`, ...
- `Think/think_01.png`, ...
- `Celebrate/celebrate_01.png`, ...
- `Turn/turn_01.png`, `Stop/stop_01.png`, `Breathing/breathing_01.png`, `Run/run_01.png` (engine-supported states)

## Notes

- The concept sheets in project assets are design references only and must not be used directly at runtime.
- Non-matching files are ignored by frame discovery.
- If a state has no valid frames yet, renderer falls back to procedural layered mascot rendering until final artwork is provided.
